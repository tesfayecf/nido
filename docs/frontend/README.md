## Documentation contract

Every frontend source file in `/app/src` must include a file header with purpose, responsibilities, inputs, outputs, dependencies, key decisions, constraints, and related links. Exported components, public functions, and critical logic blocks must include adjacent documentation that explains behavior and failure impact.

# Alerts and Notifications

## Purpose

This guide explains the follow-up workflows that help users act on property changes.

## Context

Bookmarks, alert rules, and notifications are user-scoped engagement features layered on top of tracked properties.

## Core Concepts

- **Bookmarks** save properties for quick return.
- **Alert rules** define automated follow-up conditions.
- **Notifications** present the results of those conditions and other relevant events.

## Behavior / Flow

Typical workflow:

1. bookmark a property from a list or detail page
2. create an alert rule from the property detail page or alerts area
3. wait for future runs to trigger the alert condition
4. review notifications
5. mark notifications read or unread as part of follow-up

## Examples

Examples of alert logic:

- notify when price drops below a threshold
- review unread notifications only during focused triage

# Analytics Workbench

## Purpose

This guide explains the purpose and limits of the analytics workflow.

## Context

Analytics is a decision-support surface built on the latest normalized property values. It helps users understand relative patterns quickly.

## Core Concepts

- Analytics depends on field normalization.
- Filters define the current dataset scope.
- Chart selection leads back to concrete property records.
- Analytics supports investigation; property detail pages support validation.

## Behavior / Flow

Common workflow:

1. choose a measure
2. narrow the scope with filters
3. group or segment the data
4. inspect the selected records
5. open a property for deeper review when a result looks important

## Examples

Typical outputs:

- value distributions
- grouped averages or counts
- record subsets tied to a selected chart point or segment

# App Overview

## Purpose

This document is the user-facing entry point for understanding what the product does and where to find the main workflows.

## Context

Nido is an authenticated workspace for tracking properties, extracting structured data, reviewing change over time, and following up through analytics and notifications.

## Core Concepts

- Properties are the center of the workflow.
- Source templates provide reusable extraction rules.
- Fields define the shared vocabulary used by analytics.
- Runs and snapshots show what happened during ingestion.
- Alerts and notifications help users react to change.

- add a source template
- create a tracked property
- preview or adjust selectors
- run ingestion
- review snapshots and analytics
- save the property or create an alert for follow-up
